# Richard Obenze Portfolio

A responsive Vite, React, and Tailwind CSS portfolio focused on product, growth, QA, customer support, partnerships, and community work.

## Development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run preview
```

The React component tree lives in `src/App.jsx`, with content data in `src/data.js` and the browser entry point in `src/main.jsx`. Static assets live in `public/`, and Vite writes the production build to `dist/`.
